# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 0.0.6.1

### Added

- Client appearance config (`AlmightlyStaffClientConfig`) and configuration screen (`StaffClientConfigScreen`) with Mod Menu integration on Fabric and Forge config screen registration.
- Six IDE color themes (Amethyst, Obsidian, Midnight, Emerald, Crimson, Parchment) with live preview, configurable floating-window snap distance, and border thickness.
- Automated GitHub Release and Modrinth publishing workflow.
